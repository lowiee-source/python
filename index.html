    Help & FAQs

    How do I add a new asset?
    Go to Inventory and click on + Add Asset. Fill in the required details and submit.
    Why can't I edit assets?
    Only Admin and Super Admin roles can add, edit, delete, or import assets.
    How do I report an issue?
    Click on the Report Issue button in Inventory, enter CMC code and department, and submit.
